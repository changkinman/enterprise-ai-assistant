# 漏斗式意图路由设计

## 目标

将当前三路固定加权投票改造成可分叉漏斗：高精度规则可直接处理少量确定请求；轻量候选召回保留多个业务领域；只有候选不确定或消息复杂时才调用 LLM 进行任务规划。

## 分层

1. 规则层只处理精确寒暄和单一、无连接词的高精度领域命中。
2. 轻量候选层复用本地 n-gram 向量与领域模板，返回 Top-K `BusinessDomain` 候选及分数。
3. 升级门根据候选数量、分差、低置信、消息长度和任务连接词决定是否调用 LLM。
4. 已有 `TaskPlanner` 继续负责多任务拆分、依赖验证和执行模式决策。

## 约束

- 第一层不得强制将多领域请求缩为单一领域。
- 静态 70/20/10 权重不再用于四领域任务路由。
- 所有规则、候选和升级判断必须可在无外部模型的单元测试中验证。
- LLM 失败或不可用时，只能得到单任务或澄清，不得推断并行任务。
