# EchoMind 首轮评测材料（待审核）

本目录的材料用于生成**自建脱敏评测集**，不是线上工单，也不含真实员工、客户、订单或财务数据。

## 使用边界

- 不评测当前硬编码的财务查询、故障诊断等工具；它们不代表真实外部系统能力。
- `intent_cases.json`：100 条均衡意图识别样本（10 类各 10 条）。
- `rag_documents.json` 与 `rag_cases.json`：10 篇合成的企业服务制度文档与 40 个检索问题。
- `memory_scenarios.json`：18 个工作记忆、跨会话情景记忆和摘要压缩场景。
- 端到端回答质量会复用 RAG 与记忆场景，由 LLM-as-Judge 评分，并抽样人工复核。

## 审核事项

1. 意图边界：例如“查询退款进度”归 `billing`，“提交退款动作”归 `request`。
2. 合成制度是否贴近你的目标业务；若有已授权、已脱敏的制度原文，可替换同名文档并重新标注。
3. 不含工具调用成功率、工具准确率、真实财务查询性能等结论。

## 运行后可产出的数据

| 维度 | 核心指标 | 对照 |
| --- | --- | --- |
| 意图识别 | Accuracy、Macro-F1、各类 F1、实体 Micro-F1、P50/P95 | LLM-only、Pattern-only、三路融合 |
| RAG | Recall@1/3/5、MRR、nDCG@5、检索 P50/P95 | 原始向量召回、改写+并行召回+重排 |
| 三级记忆 | 事实召回率、跨会话 Recall@K、摘要压缩率、信息保真率 | 关闭记忆、仅工作记忆、三级记忆 |
| 回答质量 | 相关性、准确性、完整性、有用性、知识依据性 | 带/不带 RAG、带/不带记忆 |

所有正式报告会同时保留逐样本预测、时间戳、模型与配置，避免只保留汇总百分比。
