# 考勤与请休假管理规范

> 版本：V1.0｜适用对象：全体员工｜说明：法定假期和特殊假期以国家法律及公司最新制度为准。

## 1. 目的

在实际工作中，本节内容应作为后续流程的判断基础。员工遇到新情况时，先确认目标、事实和影响，再选择对应的处理方式；管理者应确保相关说明能够被员工找到、理解并执行。

考勤规则应通过员工手册、系统提示和经理沟通保持一致，员工不应依赖同事口口相传来判断能否请假或如何补录。制度更新时，应同时更新申请入口、审批人和常见问题说明。

考勤记录用于支持排班、协作、薪资核算和员工休息安排，不能简单等同于个人价值或绩效结果。公司关注的是员工是否按照约定履行工作安排，以及异常情况是否及时说明和处理。所有记录都应以真实出勤和真实请假情况为基础。

规范出勤、迟到早退、请假、加班和外出管理，保障团队协作与员工休息权益。

## 2. 基本要求

具体适用时，应结合岗位、业务场景和风险程度判断，不宜只看表面形式。规则发生变化或现有说明无法覆盖时，及时向指定负责人确认，并把已经确认的处理方式记录下来，避免不同人员重复猜测。

请休假安排既要考虑员工个人需要，也要考虑项目节点、客户承诺和团队替补能力。经理审批前可以先确认是否存在不可移动事项，再与员工讨论时间调整或工作交接，而不是简单地接受或拒绝。

本规范适用于全体员工，也适用于需要参加排班、值班、出差或特殊工作时段安排的人员。不同部门可以根据业务设置具体时间和报备方式，但不能取消基本的请假、加班、休息和记录要求。涉及法定假期或特殊假期时，按适用法律和公司最新制度执行。

1. 员工应使用公司指定系统完成签到、签退或出勤确认，不得代打卡、虚报出勤。
2. 因公外出、出差或临时无法打卡，应在规定时间内补充说明并提交审批。
3. 请假原则上应提前申请，紧急情况应先向直属经理报备，事后及时补办手续。
4. 病假、婚假、产假、陪产假等需提供证明的，应按要求提交真实有效材料。
5. 加班须事前获得批准；未经批准的延时工作不当然构成公司加班安排。
6. 休假期间应完成工作交接，明确紧急联系人，不得因未交接造成业务中断。

## 3. 审批流程

为便于落地，相关人员应明确谁提出、谁审批、谁执行、谁复核以及出现问题时找谁。流程运行一段时间后，根据员工反馈和实际异常补充说明，让制度逐步适应真实工作。

员工临时无法工作时，最重要的是尽快让团队知道事实和影响。报备内容可以简短，但应包含预计时长、紧急事项处理方式和后续补办计划，避免团队在没有信息的情况下反复寻找。

员工提交申请时应说明时间、假别、影响范围和交接安排，直属经理负责判断业务承接和人员安排，人力资源负责制度解释与记录管理。审批人不能长期搁置申请，也不能要求员工提供与审批无关的隐私。遇到代理审批或紧急情况，应使用明确的替代路径。

员工提交申请 → 直属经理审批 → 必要时由人力资源复核 → 系统留存记录。跨部门项目成员请假时，应同步通知项目负责人。

## 4. 异常处理

考勤管理应兼顾规则一致和实际情况。系统漏记、突发疾病、交通中断、临时外出等情况可以按异常流程处理，但员工应尽快报备并补齐记录。对重复出现的异常，应先确认原因是个人疏忽、系统问题还是排班设计问题，再决定后续措施。

发现漏打卡、重复申请或记录错误时，应在规定期限内提交更正。多次无故缺勤、虚假申报或代打卡将按公司纪律制度处理。

## 5. 检查清单

- [ ] 本月出勤记录已核对
- [ ] 请假已完成系统审批
- [ ] 外出、出差已登记
- [ ] 加班已完成事前审批
- [ ] 休假前已完成工作交接

**出勤记录说明：**

考勤记录用于反映员工是否按照约定时间和地点履行工作安排，并不单独代表绩效评价。员工应定期查看自己的出勤记录，发现漏打卡、地点异常、审批未同步等情况时及时提出。不要等到月末或工资核算后才集中处理，以免难以还原事实。

**请假申请建议：**

请假申请应写明假别、起止时间、是否影响排班或关键交付、工作交接人和紧急联系方式。连续请假、跨节假日请假或涉及关键发布窗口的，应尽量提前与团队沟通。经理审批时应关注工作安排是否可承接，不应要求员工披露与审批无关的个人隐私。

**外出、出差与临时离岗：**

因公外出应在日历或外出系统中标注时间、地点和同行人员，必要时留下可联系渠道。出差期间仍应遵守信息安全、费用报销和客户接待要求。临时离岗时间较长时，员工应在状态中说明预计返回时间，避免同事反复寻找。

**加班管理与调休：**

加班申请应说明工作事项、预计时长、必要性和完成标准。经理应优先通过调整范围、排期或资源解决工作压力，不应把长期加班作为常态管理方式。加班完成后，员工应按公司流程记录实际情况并申请对应的休息或结算安排。

**异常场景处理：**

- **忘记打卡**：在规定期限内提交更正，说明真实出勤时间和原因。
- **审批人不在岗**：按照授权链或代理审批规则处理，不要私自绕过审批。
- **突发疾病或家庭紧急情况**：先通过电话或即时消息通知经理，随后补充正式申请。
- **系统故障导致无法提交**：保留截图或错误信息，先向人力资源报备，系统恢复后补录。
- **团队排班冲突**：由经理根据业务优先级和人员可用性重新安排，避免让员工自行承担全部协调压力。

**管理者的审批责任：**

审批人应及时处理申请，不能无理由长期搁置。对于不批准的申请，应说明业务原因和可替代安排。若员工频繁出现异常出勤、未请假缺勤或记录不一致，经理应先开展事实沟通，再根据制度采取措施，避免仅凭传闻判断。

**落地建议：**

团队每月可用几分钟检查考勤异常类型，而不是只在出现争议时处理。将常见的补卡、代理审批、病假证明和加班申请问题整理成问答，放在员工容易找到的位置。这样既能减少人力资源重复答疑，也能让员工在需要请假或临时外出时快速完成正确操作。

**员工自查：**

每月查看一次考勤、请假和加班记录，确认申请状态、时间范围和审批结果正确。需要连续休假或临时调整安排时，提前通知相关同事并留下交接信息，避免个人记录正确但团队不知道工作如何承接。

**复盘与改进：**

团队可根据高频异常优化审批提醒和排班方式，减少员工反复补录，也减少管理者临时协调造成的工作压力。

考勤记录首先是工作安排的基础信息，员工应把它当作需要定期维护的工作记录，而不是只在出现薪资问题时才查看。系统中的时间、地点、假别和审批状态如果不准确，可能会影响排班、项目协作和后续统计，因此发现问题后越早处理越好。

请假前应尽量把工作分成三类：可以提前完成的事项、可以交给同事的事项、必须等本人回来处理的事项。交接时写清文件位置、当前状态、下一步动作和需要注意的风险。对于客户响应、系统发布和固定排班等事项，还应明确替代联系人和紧急联系方法。

经理审批请假时，应综合考虑业务安排和员工合理休息，不宜只用“最近很忙”作为拒绝理由。确实存在关键交付时，应与员工讨论调整范围、改变时间或安排替代人员，而不是让员工在休假和工作之间自行承担全部冲突。

临时请假、迟到、早退或无法打卡时，员工可以先通过电话或即时消息说明情况，再补充正式流程。报备时不必透露无关的私人细节，但要让经理知道大致影响、预计恢复时间和是否需要交接。系统恢复后应尽快补录，并保留必要的沟通记录。

加班管理的重点是确认工作确实需要额外时间，而不是鼓励员工通过延长在线时间解决计划问题。团队可以在项目开始时识别高风险节点，提前安排资源和缓冲。若某类工作长期依赖加班完成，应复盘需求范围、人员配置和流程效率。

人力资源和管理者还应定期观察异常模式，例如某个团队长期没有休假、同一员工频繁漏打卡、审批总在截止时间后完成等。异常不一定意味着违规，但值得开展事实沟通，确认是否存在工作压力、系统问题或制度理解偏差。

排班岗位应提前公布班次、替班方式和临时调整规则，避免员工只能通过私聊寻找替代人员。调整排班后要同步系统和相关人员，防止纸面安排与实际工作不一致。对长期项目和关键值班岗位，可以设置备用联系人和交接模板，减少单个人员缺席带来的影响。

休假期间的联系边界也应提前说明。员工应知道哪些事项可以等到返回处理，哪些事项由代理人负责，真正紧急时通过什么方式联系。经理不能默认休假员工仍会持续在线；如果确有必须参与的情况，应提前沟通并按照相应安排处理。

病假及其他需要证明的假别，应只收集审批所需的信息，不要求员工提供与工作无关的隐私。负责审核的人员应妥善保护材料，不在团队群聊中讨论员工的健康情况。员工无法一次性提供材料时，可以先说明情况，再按照规定补交。

月度核对考勤时，除了查看个人记录，也要关注系统是否出现批量异常、审批链失效或重复提醒。发现系统问题时应统一修复，不能让员工逐个承担技术故障。相关调整完成后，向受影响人员说明处理结果，避免同类问题再次发生。

团队还可以在季度复盘时观察休假是否真正被使用、关键岗位是否有替代安排、审批是否集中在少数人员手中。良好的考勤管理不是把员工限制在固定时间里，而是在明确规则的基础上，让工作安排、休息需求和业务连续性能够互相兼容。

当制度、系统和实际安排出现冲突时，应先记录具体场景，再由人力资源和业务负责人共同调整。不要用临时口头规则长期替代正式流程，也不要让员工通过猜测管理者偏好来安排休假。规则越透明，团队越容易提前计划，管理者也越容易公平处理不同请求。

所有调整都应回到清晰、可执行和可追溯的安排上，减少临时口头规则带来的误解。
