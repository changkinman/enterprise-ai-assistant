# 员工申诉与冲突解决规范

> 版本：V1.0｜适用对象：全体员工；适用于工作冲突、不公平对待、骚扰、歧视和制度执行争议。

## 1. 处理原则

在实际工作中，本节内容应作为后续流程的判断基础。员工遇到新情况时，先确认目标、事实和影响，再选择对应的处理方式；管理者应确保相关说明能够被员工找到、理解并执行。

员工可以先判断问题是否适合直接沟通，但不必为了证明自己善意而承受不安全或不公平的对话。涉及权力差距、骚扰、威胁和报复时，直接走正式渠道更合适。

申诉与冲突处理的目标，是让员工能够安全地提出问题，让组织能够基于事实改进工作环境。公司不要求所有分歧都走正式调查，但要求涉及骚扰、歧视、威胁、安全风险或报复的事项能够被及时接收和保护。

公司鼓励及时、善意、基于事实地解决问题，遵循保密、客观、公平、避免报复和必要知悉原则。涉及人身安全、骚扰、歧视或严重违规的事项，可跳过直接沟通，直接向人力资源或合规联系人报告。

## 2. 建议流程

具体适用时，应结合岗位、业务场景和风险程度判断，不宜只看表面形式。规则发生变化或现有说明无法覆盖时，及时向指定负责人确认，并把已经确认的处理方式记录下来，避免不同人员重复猜测。

申诉材料应尽量写事实、时间和影响，避免只写对某人的总体评价。材料越具体，处理人员越容易确认问题、安排保护并判断下一步需要哪些信息。

本规范适用于工作分工、沟通冲突、不公平对待、骚扰、歧视、管理争议和员工申诉。员工可以根据风险选择直接沟通、经理介入、人力资源、合规、安全或其他指定渠道；权力差距明显时，不应强制员工先面对对方。

1. 记录事实、时间、地点、人员、影响和相关材料。
2. 在安全和适当的情况下，与对方或直属经理沟通具体问题与期望改进。
3. 无法解决或不适合直接沟通时，向人力资源、合规或指定申诉渠道提交。
4. 配合事实核查，提供真实信息，不传播未经确认的调查内容。
5. 接收处理结果和改进安排；对结果有异议时，在规定期限内申请复核。

## 3. 保密要求

为便于落地，相关人员应明确谁提出、谁审批、谁执行、谁复核以及出现问题时找谁。流程运行一段时间后，根据员工反馈和实际异常补充说明，让制度逐步适应真实工作。

接收申诉的人应控制知悉范围并说明流程，不在公开群组讨论当事人。即使暂时无法给出最终结论，也应让员工知道当前状态、联系人和补充材料的方式。

员工负责尽可能客观地记录事实和影响，接收人负责保密、转交和说明流程，调查人员负责公平核实，管理者负责提供必要的临时保护和后续改进。任何人都不能因为员工善意提出问题而打击报复或扩大传播。

参与处理的人员仅可向有必要知悉的人员披露信息。不得在群聊、社交媒体或其他非正式渠道讨论当事人隐私和调查细节。

## 4. 检查清单

适合直接沟通的事项可以先围绕事实、影响和期望改进展开。正式申诉应说明时间、地点、人员、材料和希望获得的支持。调查过程中应区分已确认事实、各方陈述和待核实信息，不要在结论形成前公开给任何人贴标签。

- [ ] 事实和证据已客观记录
- [ ] 已选择合适的沟通或申诉渠道
- [ ] 未传播隐私和调查信息
- [ ] 未对善意申诉或举报实施报复

## 5. 适合直接沟通的情况

对于工作分工、沟通方式、排期理解不一致等一般冲突，可以先与对方私下沟通。沟通前准备具体事实和希望改变的行为，不使用“你总是”“你从来不”等绝对化表达。若对方不愿沟通、权力差距明显或事项涉及骚扰歧视，则不要求员工必须先直接面对对方。

**申诉材料建议：**

申诉材料应尽量按时间顺序说明发生了什么、谁在场、造成了什么影响、是否尝试解决以及希望公司提供什么支持。可以附上邮件、消息、会议记录或其他合法取得的材料。不要把与问题无关的个人隐私、聊天记录和传闻一并传播。

**处理过程：**

接收人应确认已收到申诉，说明下一步联系人和大致处理方式。调查可能包括分别访谈、查看文件、确认流程和听取不同当事人的说明。调查期间，公司可以根据风险采取临时调整汇报关系、工作安排或沟通方式，但临时措施不等于最终结论。

**结果与改进：**

处理结果应在允许范围内向相关人员说明事实认定、采取的措施和后续安排。由于隐私或法律原因，不一定披露对他人的具体处分。员工如果认为事实遗漏或流程不公，可按规定申请复核。部门应关注制度、管理方式和团队氛围的改进，而不只是结束单个案件。

**防止报复：**

报复可能表现为威胁、排斥、恶意降级任务、故意扣留信息、散播隐私或影响评价。员工发现申诉后出现明显异常，应记录事实并立即报告。管理者不得要求团队孤立当事人，也不得因为员工提出合理问题就降低其发展机会。

**紧急事项：**

如果存在即时人身危险、暴力威胁、严重骚扰、数据泄露或其他紧急风险，应优先联系当地紧急服务、公司安全联系人或人力资源，不要等待普通申诉流程。紧急报告时先说明当前危险和需要的保护措施，细节材料可以随后补充。

**落地建议：**

公司应让员工容易找到申诉渠道、联系人和保密说明，并定期检查链接是否有效。管理者收到问题后先保护当事人和证据，再判断由谁处理，不要在团队群里公开讨论。处理结束后，可在不泄露隐私的前提下总结流程改进，让员工看到提出问题能够带来实际变化。

**员工自查：**

遇到冲突时先记录事实和影响，选择适合的沟通或申诉渠道。涉及安全、骚扰、歧视或报复时，不要为了“保持和气”而独自承受，也不要在公开群聊中传播他人隐私。

**复盘与改进：**

处理结束后在保护隐私的前提下检查流程是否及时、渠道是否可用，并把重复出现的问题转化为管理和培训改进项。

一般工作冲突可以从具体事实开始处理，例如分工、排期、沟通方式、资源和交付标准。沟通时说明发生了什么、造成什么影响、希望怎样调整，并给对方回应和补充背景的机会。不要用“你一直这样”“大家都认为你有问题”等无法核实的概括替代事实。

如果权力差距明显、对方是直接上级、已经发生骚扰歧视、存在威胁或员工担心报复，就不要求其必须先与对方直接沟通。可以直接联系人力资源、合规、安全或其他指定渠道。员工只需要说明当前情况和希望获得的保护，不必先完成一份完美的调查报告。

申诉材料应按时间顺序记录日期、地点、人员、原话或行为、影响、证人和相关文件。只提供与问题有关的材料，避免传播他人的健康、家庭、薪酬或其他无关隐私。截图和聊天记录要保留上下文，不要只截取容易被误解的一句话。

接收申诉的人应说明已收到、由谁处理、下一步如何进行以及员工可以如何补充材料。调查过程中可能会分别访谈不同人员、查看文档和确认流程。临时调整汇报关系、工作安排或沟通方式是风险控制措施，不应被直接理解为最终结论。

处理结果应在允许范围内说明事实认定、采取的措施和后续安排。由于隐私原因，公司不一定披露对他人的具体处分，但应让申诉人知道问题是否得到处理、是否存在复核渠道以及以后遇到类似情况可以联系谁。

报复可能表现为威胁、孤立、恶意扣留信息、突然改变工作评价、安排明显不合理的任务或散播隐私。员工发现申诉后出现明显异常，应继续记录并报告。若存在即时人身危险、暴力威胁或严重安全风险，应优先联系紧急服务和公司安全联系人。

员工如果选择先与对方沟通，可以提前准备希望解决的问题和最低可接受的结果。沟通时保持在合适的私密环境，必要时邀请经理或中立人员参加。若谈话让员工感到不安全、对方拒绝停止不当行为或冲突已经升级，应结束直接沟通并转交正式渠道。

申诉渠道应让员工知道可以报告什么、向谁报告、是否可以匿名、材料如何保存和大致如何处理。组织不一定能按照员工希望的方式解决每个问题，但应说明流程和结果边界，避免员工长期等待或只能从传言中了解进展。

调查人员需要听取不同当事人的说明，区分已确认事实、各方陈述和仍待核实的信息。处理过程中不应提前承诺处分，也不应因为某人的职位、业绩或资历就降低调查标准。必要时可以请法务、合规、心理支持或安全人员参与。

团队中发生冲突后，恢复工作关系可能比完成一次调查更需要时间。管理者可以在适当情况下重新明确角色、沟通方式、会议规则和信息共享边界，但不应强迫当事人立即恢复私人关系。所有安排都应以安全、尊重和正常工作为前提。

申诉数据可以帮助组织发现重复性的管理问题，例如目标不清、晋升标准不透明、团队存在排斥行为或某个流程长期制造冲突。去除个人身份后，这些趋势可以用于培训和制度改进，但不能用来追踪、猜测或公开识别申诉人。

处理冲突时既要保护提出问题的人，也要避免未经核实就给其他人贴标签。事实调查、必要保密和公平听取各方意见能够减少二次伤害。管理者如果发现团队成员不愿意表达、信息长期被截留或同类冲突反复出现，应把它视为管理信号，及时调整沟通和决策方式。

申诉和冲突处理不是为了让每个人都得到完全相同的结果，而是确保事实被认真听取、程序相对公平、人员安全受到保护。处理人员应说明哪些内容能够确认、哪些仍然未知、下一步如何进行，并允许相关人员在规定范围内补充信息。

管理者平时就应建立可沟通的关系，而不是等到正式申诉发生后才第一次询问员工感受。通过定期一对一、清晰目标和及时反馈，可以提前发现排斥、误解和资源冲突。即使问题最终需要正式处理，日常积累的信任也能帮助员工更准确地表达事实，并减少对流程的担心。

清晰、公平和保密的处理方式，能够帮助员工恢复工作秩序并推动组织持续改进。
