# 混合办公与远程办公规范

> 版本：V1.0｜适用对象：获准采用混合或远程办公安排的员工。

## 1. 目的

在实际工作中，本节内容应作为后续流程的判断基础。员工遇到新情况时，先确认目标、事实和影响，再选择对应的处理方式；管理者应确保相关说明能够被员工找到、理解并执行。

远程办公地点应满足基本的安静、稳定网络和隐私条件，员工不应在他人可以看到屏幕或听到客户讨论的地方处理敏感工作。地点发生变化时，仍应遵守设备和数据保护要求。

混合办公的核心不是改变员工责任，而是改变工作地点和协作方式。公司应确保员工无论在办公室、家中或其他批准地点，都能获得完成工作所需的信息、工具和支持。办公地点安排应服务于业务目标，不应成为缺乏明确目标的替代品。

在保障信息安全、工作效率和团队协作的前提下，明确非固定办公地点的工作要求。

## 2. 适用原则

具体适用时，应结合岗位、业务场景和风险程度判断，不宜只看表面形式。规则发生变化或现有说明无法覆盖时，及时向指定负责人确认，并把已经确认的处理方式记录下来，避免不同人员重复猜测。

经理安排远程工作时应明确当天或本周的交付结果，而不是只要求员工保持在线。员工应把任务状态、阻塞点和需要协助的事项写在团队约定的位置，让同事能够在不打断的情况下了解进度。

本规范适用于经批准采用远程、弹性或混合办公安排的员工，也适用于需要临时异地工作的人员。岗位是否适合远程，应综合考虑客户要求、数据敏感度、设备条件、现场协作和安全风险。临时远程安排应明确起止时间，长期安排应定期复核。

- 远程办公安排须经直属经理批准，并符合岗位性质、客户要求和公司安全条件。
- 员工应在约定工作时段保持可联系，及时响应会议、消息和工作任务。
- 工作地点应具备稳定网络、适当照明和能够保护公司信息的环境。
- 远程办公不改变岗位职责、工作目标、考勤和绩效要求。

## 3. 信息安全要求

为便于落地，相关人员应明确谁提出、谁审批、谁执行、谁复核以及出现问题时找谁。流程运行一段时间后，根据员工反馈和实际异常补充说明，让制度逐步适应真实工作。

混合团队需要有意识地安排信息共享，不能把重要决定只留在办公室现场。会议纪要、项目看板和异步说明应让不同办公地点的成员都能及时获得同样的背景和参与机会。

员工负责保持约定时段的可联系状态、完成交付、保护设备和信息；经理负责明确目标、设置协作节奏和提供必要支持；IT 与行政负责安全连接、设备和办公资源。任何一方遇到条件变化，都应尽早沟通，不要等问题影响交付后才说明。

1. 优先使用公司设备和受管控网络，禁止在公共电脑处理公司文件。
2. 通过 VPN、企业网盘或公司批准的系统访问业务资料，不得将文件转发至个人邮箱或个人网盘。
3. 会议应使用耳机或私密空间，避免家人、访客或公共场所人员看到或听到敏感内容。
4. 设备丢失、网络异常、疑似泄密或误发文件时，应立即向 IT 和直属经理报告。

## 4. 协作要求

远程工作应以结果和协作为主要判断依据。团队需要明确核心协作时间、紧急联系渠道、文档入口、会议规则和进度同步方式。对于不要求实时参与的工作，优先采用异步文档和项目看板；对于需要共同决策的事项，保留必要的在线或现场会议。

员工应在日历中标明工作地点和可用时段，重要任务使用统一项目工具跟踪，并在下班前更新进度、风险和次日计划。

## 5. 检查清单

- [ ] 已获得远程办公批准
- [ ] 工作地点可保护公司信息
- [ ] 使用公司设备及安全连接
- [ ] 日历和状态已更新
- [ ] 重要工作已同步进度和风险

**远程办公前的准备：**

员工应提前确认电源、网络、耳机、摄像头和必要的软件均可使用。涉及客户会议、系统发布或重要评审时，应准备备用网络或电话方案。工作地点不宜选择容易被他人看到屏幕、听到会议内容或接触公司设备的场所。

**工作时间与可联系状态：**

远程办公不是“随时在线”，也不是“完全失联”。团队应约定核心协作时间、日常同步方式和紧急联系方法。员工短时间离开设备时更新状态；超过约定时段无法联系时，应提前通知经理或项目负责人。

**会议与协作方式：**

线上会议开始前检查麦克风和共享权限，会议中不共享包含无关敏感信息的完整桌面。需要共同编辑的资料应放在统一空间，避免多人各自维护不同版本。会议结束后同步结论、行动项和截止时间，不能默认“参加过会议就代表已经知悉任务”。

**家庭和公共环境边界：**

员工应尽量把工作设备放在儿童、访客和宠物不易接触的位置，不让他人代为操作设备。公共场所办公时应使用隐私屏、耳机和加密连接，避免在咖啡店、交通工具或共享办公区讨论客户名单、薪酬、源代码和安全事件。

**远程办公中的异常处理：**

- **网络中断**：通过手机或备用网络通知团队，保存本地未同步的工作并避免重复提交。
- **设备丢失**：立即报告 IT，按指导锁定、擦除或冻结设备和账号。
- **会议误入访客**：立即停止共享敏感内容，确认参会人员后重新开始，并报告可能的暴露范围。
- **无法按时交付**：尽早说明原因、影响和新的可行时间，不要等到截止时间过后才反馈。

**经理的管理建议：**

经理应以交付结果、协作质量和响应情况评价远程工作，不以摄像头常开、鼠标活动或频繁汇报替代明确目标。团队可设置固定的周会、异步日报或项目看板，但应避免重复收集同一信息。

**落地建议：**

团队开始采用混合办公时，建议先约定几条简单规则：核心协作时段、紧急联系人、文档存放位置、会议纪要方式和请假报备方式。试运行一段时间后，根据成员反馈调整，不必一开始就设计复杂的在线监控或过多汇报表格。

**员工自查：**

远程办公前确认设备、网络、空间和日历状态；工作结束时同步进度、保存文件并锁定设备。若连续出现无法联系、网络不稳定或资料难以协作的情况，应及时和经理一起调整安排。

**复盘与改进：**

每月收集一次远程协作中的阻碍，优先改进资料位置、会议节奏和应急联系人，不把问题简单归因于员工是否在线。

混合办公安排应先把工作目标和交付方式说清楚，再讨论员工在哪个地点工作。对于需要现场设备、客户接待或高频面对面协作的岗位，可以设置固定办公时段；对于以文档、代码、工单和线上会议为主的工作，则可以更多采用异步协作。不同岗位不必完全使用同一种安排。

远程工作开始前，员工应确认公司设备、电源、网络和安全连接均可用，并提前下载必要的非敏感材料。涉及大型文件、生产变更或客户演示时，应准备备用方案。若网络不稳定，应尽早通知团队，而不是在会议开始后才突然消失。

线上协作时，最好把工作状态分成“可立即沟通”“专注工作”和“暂时离开”几类，并使用统一的状态说明。这样同事可以判断应该发消息、安排会议还是等待回复。团队也应约定真正紧急事项的渠道，避免把所有事情都标记为紧急。

远程会议应尽量有明确结果。会前把背景材料和问题发出，会中记录决定和分歧，会后同步负责人和截止时间。无法参加会议的人可以通过异步文档提供意见，不应因为没有出席就自动失去参与决策的机会。

家庭环境与公共空间可能带来隐私、噪音和安全问题。员工应避免让他人看到屏幕、听到客户信息或操作公司设备。使用公共网络时应遵守公司的安全连接要求，离开座位时锁屏，结束工作后收好纸质文件和设备。

经理评估远程工作时应看交付结果、质量、协作和响应，而不是要求员工全天开启摄像头或频繁发送无意义的状态。若某项工作确实需要更密集的同步，应说明原因、周期和结束条件，避免临时监控逐渐变成长期管理方式。

团队使用项目工具时应有统一的记录习惯，例如任务状态、负责人、截止时间和阻塞原因放在同一个看板中。不要让员工同时维护多个日报、表格和群消息。信息入口越少，远程成员越容易了解项目真实状态，也越容易在需要时接替工作。

远程办公时遇到家庭、健康、网络或场所变化，可以提前与经理讨论临时调整，不必等到影响已经发生才解释。调整可以包括更换办公地点、改变会议时间、减少当天任务或临时到办公室工作。安排应有明确期限，并在情况恢复后重新确认。

跨地域团队还要注意时间、语言和文化差异。会议邀请应标明时区，重要决定给无法参会者留出反馈时间，书面说明尽量少用只有本地团队能理解的缩写。尊重不同工作节奏，有助于减少误解和重复确认。

公司提供的远程办公设备和网络资源属于工作资源，员工应按照信息安全要求使用。不要把公司账号交给家人，也不要在共享电脑上保存登录状态。打印的内部文件、会议白板和录音同样需要在任务结束后妥善处理。

如果远程安排持续造成沟通延迟、员工孤立或工作边界模糊，经理应与团队一起调整规则，而不是简单增加会议。可以减少低价值同步，增加关键节点的面对面沟通或一对一交流，让团队既保持效率，也保持必要的信任和支持。

混合办公安排也应定期检查公平性，例如远程员工是否能够获得同样的项目信息、培训机会和反馈，现场员工是否承担了过多临时协助。管理者可以根据工作结果和团队反馈调整安排，不把办公地点直接等同于投入程度，也不让地点差异影响不相关的评价。

如果某种办公安排只适合一部分岗位，应向员工解释差异来自工作性质和安全要求，而不是个人偏好。涉及例外时记录期限和审批人，定期确认是否仍有必要。清晰的理由和可复核的标准，能够减少员工之间的猜测，也能帮助团队在变化时平稳调整。

定期回看协作效果并及时调整，能够让办公方式随着团队和业务变化自然演进。
